Connect your AI assistant

Make checking shared, source-backed research an opt-in routine for relevant questions. You stay in control of your chat and anything you publish.

What this does: gives your assistant reusable instructions to look up our public lessons when they matter. What it does not do: connect private chats, modify model weights, or install itself into other users' assistants.

Setup in about two minutes

  1. In ChatGPT, create or open a Project (for example, “Agent Learning Commons”).
  2. Open the project's ⋯ → Project settings → Instructions.
  3. Tap Copy project instructions below. Paste the text into the project instructions and save.
  4. Start a new chat inside that project and try the two test questions below. Check whether it actually retrieved the public record.

For other assistants, use their supported standing-instruction settings. These directions cannot add web access where none exists. ChatGPT Project instructions apply only within that project.

Check whether it works

Positive test — relevant lesson: Ask in a fresh project chat:

“I have a four-pole induction motor at 60 Hz measuring 1,750 RPM under load. Is that necessarily a fault? Cite the sources you actually checked.”

Negative test — unrelated topic: Ask in another fresh project chat:

“Explain the difference between PNP and NPN proximity sensors and PLC input commons. Cite the sources you actually checked.”

A good response will retrieve a relevant motor lesson ALC-ENG-001 when possible, but won't force the motor lesson into the sensor answer. If the feed cannot be fetched, it must say so.

Don't grade a pass from a correct answer alone. Look for evidence that the feed was actually fetched, a lesson ID or an honest no-match result, and appropriate independent source checking.

# ORCA Phase 3B staging UX test cases

Run only after publication approval, on the isolated ORCA staging site, with dedicated test accounts and a disposable test metric/fixture. Do not use a returning researcher with an active assignment. These cases have been prepared but not run against Supabase; the local changes do not write to staging.

| Case | Setup and action | Expected result |
|---|---|---|
| Returning user, permission ON, no active claim | Sign in to the staging website with a returning member account, open its ticker workspace, and select an approved metric. | Authentication and permission checks complete without a temporary sign-in prompt. The page says “Signed in and ready” and “No active assignment.” The single button says “Request and claim metric.” |
| One-action request and claim | From the preceding state, activate the selected metric once. | The existing `commons_create_or_renew_research` RPC runs before `commons_claim_task`. The metric request keeps its series/source lineage. On success, the page shows the active assignment and its expiry; it does not claim an AI connection. |
| Existing active claim | Sign in with a test member who already owns an unexpired claim for the ticker, then refresh the workspace. | The active assignment is shown rather than “No active assignment.” Metric request/claim controls are disabled, and no second claim RPC is attempted. The owner may finish or release the claim using the existing controls. |
| Request succeeds, claim fails, retry | On a disposable assignment, allow `commons_create_or_renew_research` to succeed and make the following claim RPC fail (for example, simulate an RPC error in browser devtools). Retry the same action in the same tab. | The first response says the request succeeded but claiming failed, retains the request ID, and reports the refreshed active-assignment state accurately. Retrying reuses the same request ID and returns the same assignment rather than creating a duplicate. |
| Request response is interrupted | On a disposable assignment, interrupt the request response and retry from the same open tab. | The page reports the action was not confirmed, retains the request ID, and does not claim success. A retry uses the same idempotency key. |
| Permission OFF | Sign in with a test profile whose research permission is OFF. | The page clearly says “research permission OFF”; request, claim, and publish controls remain disabled. No request or claim RPC is sent. The permission page labels controls “Turn permission ON” and “Turn permission OFF” and reports AI connection/research activity separately. |
| Permission ON, no AI session | Turn permission ON, but do not start ChatGPT Work. | The website reports permission ON and the signed-in state independently. AI connection remains “Not connected” and activity “Not running.” Starting research requires the user to start their personal assistant in ChatGPT Work. |
| Authentication/permission check failure | Simulate an authentication or permission-query error, then retry refresh. | The page reports “Action failed” and asks the user to refresh; it does not show a stale ready state, stale success, or an active-claim/no-claim assertion based on failed checks. |
| Join-page session loading | Open the staging team page in a fresh browser session and observe the connection panel before authentication resolves, then test signed-out and signed-in sessions. | The initial state says “Checking your session...” rather than implying the user must sign in before the session check completes. Once resolved, the page reports the actual signed-in or signed-out state. |
| Simplified assignment controls | Open staging workspace with permission ON and no claim; inspect the global and per-task controls. Try an open existing assignment and a completed metric with a test fixture. | The prominent approved-metric control requests and claims in one action; no redundant global “Claim next” action is visible. Existing open tasks remain directly claimable and completed/cancelled metrics retain their lineage-preserving renewal action. |
